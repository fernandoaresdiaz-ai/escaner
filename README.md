# Escáner

App web para iPhone que escanea hojas y las deja planas en PDF, sin anuncios ni marca de agua.
Todo se procesa en el propio móvil: ninguna foto sale del teléfono.

- Detección automática de esquinas en directo, con ajuste manual opcional
- Filtros: sin sombras, color original, escala de grises, blanco y negro
- Varias páginas por documento: reordenar, girar y borrar
- Historial de documentos guardado en el móvil, con nombre automático
- Exportar PDF en tres tamaños (alta, correo, mínima) y linterna si el móvil lo permite

Abrir en Safari: https://fernandoaresdiaz-ai.github.io/escaner/ y "Añadir a pantalla de inicio".
